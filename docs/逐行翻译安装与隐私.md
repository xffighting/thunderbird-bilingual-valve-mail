# Thunderbird 正文逐行中英对照

## 使用效果

```text
Please quote your best price and delivery time.
译 请提供最优价格和交期。

Ball valve DN50 PN16 WCB.
译 球阀 DN50 PN16 WCB.
```

英文原文不会被覆盖。译文只是阅读层显示，关闭扩展后原邮件保持不变。

## 隐私数据流

```text
Thunderbird 邮件阅读页
  → 扩展后台
  → Thunderbird Native Messaging
  → 本机 Argos Translate
  → 中文译文返回阅读页
```

- 不使用 Google Translate、DeepL、OpenAI 或其他云端翻译 API。
- 不开放本地 HTTP 端口。
- 默认不保存邮件正文和译文历史。
- 只有用户主动点击“纠错”时，所填写的英文短语、当前译文和建议译文会保存在 Thunderbird 本机扩展存储中；可在设置页批准或忽略。
- 不发送、移动、删除或修改原邮件。
- 默认不翻译引用历史和签名。

## macOS 安装

在源码目录执行：

```bash
zsh native-host/install_macos.sh
```

安装位置：

- 本机组件：`~/Library/Application Support/Lianggu/MailTranslator/`
- Thunderbird 通信清单：`~/Library/Mozilla/NativeMessagingHosts/com.lianggu.mail_translate.json`

## Thunderbird 设置

进入扩展设置：

1. 勾选“打开邮件时自动翻译英文正文”。
2. 点击“检查离线翻译”。
3. 可点击“运行质量评测”，用 6 条内置脱敏样本选择最佳本机模型。
4. 显示“离线翻译可用”后，重新打开一封英文邮件。

“同时翻译引用的历史邮件”默认关闭。只有确实需要阅读整段往来时再开启。

## 术语与纠错

1. 在设置页“专业术语库”添加英文术语和标准中文译法。
2. 自定义术语优先于内置的 153 条阀门与外贸术语。
3. 在邮件译文旁点击“纠错”，记录会进入设置页“纠错待确认”。
4. 只有点击“批准为术语”后，纠错才会影响后续翻译。
