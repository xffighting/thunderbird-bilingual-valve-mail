# Thunderbird 销售邮件助手 v0.3 Agent 小组

## 小组结构

| Agent | 职责 | 本轮交付 |
|---|---|---|
| 产品架构 Agent | 第一屏信息顺序、schema、缺数据状态、客户背景抽屉 | 将界面收束为“询价、项目、客户、订单”四类决策信息 |
| 客户情报规则 Agent | 客户匹配、客户重要度、历史订单边界、钉钉映射 | 定义唯一邮箱/域名匹配、公共邮箱护栏、未知客户不评级 |
| Thunderbird QA Agent | Manifest V3、128+ 兼容、权限、URL 安全、打包 | 找出旧 messageDisplay API 和 TB151-only manifest 阻断 |
| 主 Agent | 统一数据合同、实现、回归、视觉验收、打包 | 完成 v0.3.0 源码、测试、预览图和 XPI |

## 协作接口

1. 邮件提取层只处理会话正文和邮件头，不把会话订单信号写成客户历史订单。
2. 客户情报层只消费用户主动导入的只读主数据。
3. 身份自动确认只接受唯一精确邮箱，或唯一非公共公司域名。
4. UI 层必须展示置信度、冲突、缺字段和数据来源。
5. 钉钉层只打开白名单链接，不负责创建、修改或回填。
6. QA 层用合成邮件和模拟客户资料测试，不读取或输出真实客户正文。

## 后续适合继续委派的角色

- 本地数据适配 Agent：从良固客户资产与正式商机索引生成脱敏客户快照。
- 附件解析 Agent：只读提取 BOQ/Excel/PDF 中的项目、数量和规格。
- 真实环境验收 Agent：在隔离 Thunderbird 测试 profile 中加载 XPI，验证按钮、缓存和长线程性能。
- 安全审核 Agent：复核客户快照字段、钉钉白名单与发布权限。
